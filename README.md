# Elghamry — The Series

A streaming-inspired portfolio website for **Mohamed Elghamry**: Computer Engineering graduate focused on AI & Machine Learning, Data Engineering and Computer Vision.

**Live site:** https://elghamry-portfolio.netlify.app

## What's inside

- Opening sequence and "Who's watching?" profile picker
- Seasons and episodes telling the journey, from education to leadership and projects
- Three projects: TomatoLeafAI, Wearable Fall Detection Belt, Cisco Packet Tracer Network Project
- Top Moments, skills, certifications and a built-in resume viewer

## Built with

Vite, React, TypeScript, Tailwind CSS and Framer Motion.

## Run it locally

Requires Node.js 18 or newer.

```bash
npm install
npm run dev
```

Then open the URL Vite prints (usually http://localhost:5173).

Production build:

```bash
npm run build
npm run preview
```

## Editing the content

All the text on the site comes from `src/data/portfolio.ts`. Put your CV in `public/assets/` and your photo in the same folder.
